
This pull request introduces OpenID Connect (OIDC) authentication to the application, providing a new, standards-based way for users to authenticate. It adds a modular authentication framework with support for OIDC, password, and proxy-based identity providers. The changes include new configuration options, a router for OIDC endpoints, and logic to load and merge OIDC configuration from both the config file and the database.

**OIDC Authentication Integration:**

* Added a new `oidcOptions` struct to `conf/configuration.go` and set up default OIDC-related configuration options, enabling OIDC to be configured via config file or environment variables. * Added logic to load OIDC configuration from the database and merge it with file-based configuration, ensuring runtime updates are possible (`core/auth/oidc/config.go`).
* Integrated the OIDC router into the main server startup, mounting it at `/api/oauth` and ensuring configuration is loaded at startup (`cmd/root.go`).
